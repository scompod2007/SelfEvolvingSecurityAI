**Issue 1 — Severity: Critical**
**Location:** `tests/confidence_pipeline_test.py`, ran from `tests/` directory or via `python tests/confidence_pipeline_test.py` from root
**Root Cause:** The file has no `sys.path` bootstrap (unlike every sibling in `tests/`, e.g. `manual_filefilter_test.py` line 6, which does `sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))`). **Fix:** Add, immediately after the top-level imports and before the `try:` block:
```python
import os
sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))
```
(also add `import os` to the import list, since it isn't currently imported in this file).
